# Llama AI Studio 1.9.1

**Install:** `LlamaAIStudio-1.9.1-release.apk` (arm64-v8a, Android 12+).
SHA-256: `c0452c9985f9da1858494a1cfe02c852dde1675e35abe539c0f14480ffa07249`

Signed with a debug key (sideloading). Future updates must use the same key to install over it.

## Highlights
- Two on-device engines: **llama.cpp** (GGUF; CPU or GPU + CPU via Vulkan with auto-fit) and
  **LiteRT-LM** (`.litertlm`; GPU / CPU / NPU). Benchmark and Auto-tune work for both.
- **OpenCode** free cloud models (API key in Settings), incl. an image assistant.
- Chat with **Sessions**, **Web Studio** with built-in server + live reload, **Dev Studio**
  building APKs on the phone in the built-in **Alpine Linux (proot)**, local image generation
  and img2img edits.
